# 🤖 Compliment Bot 3000

> A chaotic little command-line tool built for Hack Club that screams random, overly enthusiastic compliments at you when you're feeling down.

![Compliment Bot Demo](https://via.placeholder.com/800x400.png?text=Compliment+Bot+3000+Screenshot)

---

## 🌟 What is this?!

Was coding getting you down? Did you need a machine to validate your existence at 2:00 AM? Look no further. **Compliment Bot 3000** takes a list of pre-written, highly dramatic compliments and blasts them onto your terminal with far too many exclamation marks. 

Built purely out of boredom and a desperate need to procrastinate on homework.

---

## 🚀 Features

* **Instant Validation:** Press `Enter` to receive a random ego boost.
* **Aggressive Positivity:** Uses all-caps formatting so you *know* it means it.
* **Zero Practical Use:** Absolutely no real-world value, guaranteed!
